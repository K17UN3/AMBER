# 機能仕様：レシート読み取り（OCR）

## 概要
Reactで取得した画像をDjango REST APIへ送信し、PaddleOCRワーカーが解析した結果を返す。

## ワークフロー
1. **Frontend**: `input type="file"` またはカメラ起動で画像を取得。
2. **Frontend**: FormData形式でDjango APIへ送信。
3. **Backend**: 画像を保存してOCRジョブをPostgreSQLへ登録し、`202 Accepted`を返す。
4. **OCR Worker**: PaddleOCRで全文・文字座標・信頼度を抽出し、ジョブへ保存する。
5. **Backend**: `GET /api/receipts/ocr-jobs/<uuid>/` で解析状況と結果をJSONで返却する。
6. **Frontend**: 解析結果をフォームに自動入力し、ユーザーに確認を促す。
7. **Frontend**: ユーザーが確認・修正後、保存ボタンを押す。
8. **Backend**: 確認済みデータを支出データとしてDBに保存する。

## エンドポイント案
- `POST /api/receipts/analyze/`: 画像解析ジョブを登録する
- `GET /api/receipts/ocr-jobs/<uuid>/`: OCRジョブの状態・結果を取得する

## 注意点
- OCR解析時点ではDB保存しない。
- ユーザーが確認・修正して保存した後にDBへ登録する。
- OCRの読み取りミスに備えて、日付・店名・合計金額・カテゴリーは手動修正できるようにする。
- 保存時に、OCRの抽出値と修正後の支出値を修正履歴として保存する。
- 本番のAPIとWorkerは、同じレシート画像へアクセスできる共有ストレージを使用する。
