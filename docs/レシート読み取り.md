# 機能仕様：レシート読み取り（OCR）

## 概要
Reactで取得した画像をTesseract.jsでブラウザ内解析し、確認済みの支出データだけをDjango REST APIへ送信する。

## ワークフロー
1. **Frontend**: `input type="file"` またはカメラ起動で画像を取得。
2. **Frontend**: Tesseract.jsのWeb Workerで日本語・英語の全文と信頼度を抽出する。
3. **Frontend**: OCR全文から店名・購入日・合計金額を抽出し、フォームへ自動入力する。
4. **Frontend**: ユーザーが確認・修正後、保存ボタンを押す。
5. **Backend**: 確認済みデータとOCR抽出値を支出・修正履歴としてDBに保存する。

## 利用エンドポイント
- `POST /api/expenses/`: 確認済みの支出とOCR抽出値を保存する

## 注意点
- OCR解析時点ではDB保存しない。
- ユーザーが確認・修正して保存した後にDBへ登録する。
- OCRの読み取りミスに備えて、日付・店名・合計金額・カテゴリーは手動修正できるようにする。
- 保存時に、OCRの抽出値と修正後の支出値を修正履歴として保存する。
- レシート画像はブラウザ外へ送信・保存しない。
- 初回は日本語・英語の学習データをダウンロードするため、解析開始まで時間がかかる場合がある。
- 複数画像では同じWeb Workerを再利用する。
